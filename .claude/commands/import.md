# Import Command

将日志 md 文件导入到 `日志/` 目录。支持扫描根目录或指定文件路径。自动识别→合并→去重→清理原始文件。

## Input

文件路径（可选）从: `$ARGUMENTS`

- **无参数**：扫描根目录 `*.md`，导入所有可识别的日志文件
- **文件名**：导入根目录下的指定文件（如 `2026-7月日志.md`）
- **路径**：导入任意路径的文件（如 `~/Downloads/xxx.md`）

## Execution Steps

### 1. 确定目标文件

**无参数时**：Glob 扫描根目录 `*.md`，排除白名单文件：
`README.md`、`LICENSE`、`CLAUDE.md`、`PROJECT_STATUS.md`、`CHANGELOG.md`、`SETUP.md`、`VERSION`

如果无候选文件，告知用户"未找到可导入的日志文件"并停止。

**有参数时**：使用参数作为文件路径。相对路径从项目根目录解析，绝对路径直接使用。检查文件是否存在，不存在则报错。

### 2. 验证日志文件

逐个读取候选文件，检查内容是否匹配日志特征：

- **日期头**：`# N月`、`## N月N日`、`幸福日志 N.N`、`日志 N.N`
- **日志字段**：开心的事情/充实的事情/感谢的人/思考/待改进

不匹配则跳过："[文件名] 未识别为日志文件，跳过。"

### 3. 解析并导入

**导入前检查**：用 Bash `mkdir -p 日志` 确保目录存在（首次使用时自动创建）。

对每个匹配的日志文件：

**a. 按日期头拆分**：扫描文中所有日期头，将内容切分为每日条目。

**b. 确定目标文件**：从日期提取月份 → 先 glob `日志/*N月*.md` 查找已有文件；找到则追加，未找到则新建 `日志/YYYY-N月日志.md`。跨月内容自动拆分到不同月文件。

**c. 去重**：读目标月文件。检查每个日期的日期头是否已存在。
- 已存在 → 跳过，计数
- 不存在 → 追加（条目之间两个换行分隔）

**d. 年份推断**：默认当前年份。如果月文件已存在同月内容，使用已有文件的年份。

### 4. 清理

导入完成后，删除根目录（或用户指定路径）的原始文件。

### 5. 回报

```
📥 导入完成

| 文件 | 新增 | 跳过 | 目标 |
|------|:--:|:--:|------|
| 2026-7月日志.md | 15天 | 3天 | 日志/2026-7月日志.md |

📊 日志/2026-7月日志.md 现在覆盖 30/31 天
```

如有跨月拆分，每个目标文件一行。导入后可提示：可以运行 `/monthly-review` 生成月度复盘报告。

## Error Handling

| 情况 | 处理 |
|------|------|
| 根目录无候选文件 | "未找到可导入的日志文件。将日志 md 文件放到项目根目录后运行 `/import`。" |
| 文件不匹配日志格式 | "[文件名] 未识别为日志文件，跳过。" |
| 所有日期均已存在 | "[文件名] 中的 N 天日志均已存在，无需导入。" |
| 指定路径不存在 | "文件不存在：[路径]" |
| 跨月内容 | 自动拆分，分别导入对应月文件 |

## Notes

- 命令直接执行，不依赖代理或 workflow——导入操作逻辑简单
- 去重依据：目标月文件中是否已存在相同日期的日期头
- 根目录白名单文件不会被误扫描
- 原始文件导入后删除，保持根目录整洁
