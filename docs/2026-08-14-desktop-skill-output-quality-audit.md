### 质量的真实约束（事实，非缺陷）

桌面端每次生成是**单次提示词调用 + 结构化 JSON + 确定性渲染**；Skill 系统由 agent 编排多文件读取（视角层、analysis-standards、画像）。因此桌面端深度上限低于 Skill，但换来的是：输出结构可测试、护栏由代码强制（不依赖模型自觉）、可追溯（promptVersion）。这正是双运行时架构的设计取舍，符合"接近也行"的验收口径。
