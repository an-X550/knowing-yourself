# Archive

这个目录只存放“不再活跃，但仍需保留引用价值”的历史文档。

## 进入归档的条件

- 已被新的正式 spec、规范或状态文档替代
- 只保留历史决策背景，不再作为当前执行依据
- 内容仍可能被 README、CHANGELOG 或历史复盘引用

## 不应放入归档的内容

- 当前生效的运行契约
- 当前版本仍在执行的 spec / plan
- 仍在频繁补写的过程文档

## 维护规则

1. 归档前先确认 README、PROJECT_STATUS 或正式 spec 已指向新的权威来源。
2. 归档后的文档不再承担“当前真相”职责。
3. 如果只是临时草稿或未采纳方案，优先删除或留在过程目录，不默认进入 archive。
