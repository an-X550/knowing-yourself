# 主题思考首稿轻量优化：进度

- 目标：让首次回复在不增加用户成本下形成“问题→依据/约束→判断→行动或等待”的闭环。
- 顺序：基线测试与契约审阅 → 最小规则补强 → 三例单次回放 → 回归、导出和发布。
- 最大风险：为完整而新增栏目、行动或补充信息请求。
- 决策：保留单一运行契约；只增加“答案已闭环即结束”的规则与最小静态断言。
- 回放：三例各一次均闭环，无明显重复、无依据断裂或额外用户成本；未触发重放。
- 验证：反向移除新规则后主题契约测试按预期失败；还原后三条回归与 `git diff --check` 均通过。
- 发布：已更新版本与发布记录，待导出用户版并做最终复验。
