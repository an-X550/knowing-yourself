# 需求目标

为用户提供将分析结果导出为 CSV 文件的功能，便于在 Excel/Google Sheets 中进一步处理或存档。

> 作为日志分析用户，我想要将每日/每周/每月的分析数据导出为 CSV 格式，以便在电子表格中进行自定义筛选、统计和长期追踪。

# 边界约束

- 不做什么：不导出原始日志内容（仅导出分析评分和关键指标）
- 不做什么：不支持 PDF/JSON 等格式（本次仅 CSV）
- 影响范围：新增一个导出命令 + 一个导出逻辑模块；不影响现有分析代理的核心逻辑
- 技术约束：输出文件放在 `output/exports/` 目录（gitignored）；CSV 使用 UTF-8 BOM 编码以兼容 Excel 中文

# 验收标准

- [ ] 新增 `/export-csv` 命令，接受日期范围参数（如 `2026-06-01..2026-06-30`）
- [ ] 导出内容至少包含：日期、总分(30)、六步法各项得分、检测到的典型问题及严重度
- [ ] 支持单日、周范围、月范围三种粒度
- [ ] CSV 文件保存在 `output/exports/analysis-YYYY-MM-DD.csv`
- [ ] CSV 用 Excel 打开时中文不乱码
- [ ] 导出完成后向用户报告文件路径和记录数

# 实施计划

1. 创建 `.claude/commands/export-csv.md` — 命令入口，解析参数，调用导出代理
2. 创建 `.claude/agents/export-csv.md` — 导出代理：读取分析文件，提取评分数据，生成 CSV
3. 在 `PROJECT_STATUS.md` 中记录新命令和代理的进度
4. 在 `README.md` 的命令列表中添加 `/export-csv` 说明
5. 测试：对已有2份日分析样本执行导出，验证 CSV 格式正确
