# 「有限精力、选择性投入与不亏欠感」重写设计

## 目标

将现有主题重写为以 Nozomi 发言为主线的个人判断准则：不再平均地挂念所有问题，而是将注意力集中到会长期影响选择权、关系环境、财务安全和自我塑造的少数变量。

## 采用结构

该主题采用经用户确认的自定义结构，取代默认 0–6 模板。原因是它的首要用途是作为一张“关切优先级地图”被调用；标准模板会把同一判断拆散到问题、行动与验证中，增加阅读摩擦。

正文依次包含：

1. 可直接调用的总原则；
2. Nozomi 发言原文及用户的完全认可；
3. 第一性原理复核（真实问题、事实/假设、约束、价值选择）；
4. 四类优先资产（投资能力、关系环境、财务安全、价值一致与自我塑造）；
5. 焦虑筛选器（长期选择权、不可替代性、不可逆性、累积效应）；
6. 边界校正与相邻主题转向；
7. 观点演化与复查条件。

## 内容边界

- 原文完整写入并标注为 Nozomi 的发言；用户认可的是其优先级方法。
- “十年存款”等具体阈值只作为 Nozomi 的个人标准，不写成用户已达成的事实或用户的固定金额目标。
- 不把“不挂念”写成冷漠、逃避承诺或忽视健康、信誉、关系修复等有长期累积效应的事项。
- 本主题只处理注意力与关切的优先级；日程容量转“精力管理”，行动主权转“坚定相信自己”，关系具体经营转“真诚、利他与共事关系”。

## 验收

- 主题 frontmatter 标明自定义 `format` 和唯一 `semantic_role`。
- 不使用 0–6 标题，但保留当前调用入口、事实/推断/价值区分、来源与反例校正、可观察的复查条件，以及观点演化。
- 原文完整保留；不将其个人事实误写成用户事实。
- 链接指向的相邻主题均存在。
