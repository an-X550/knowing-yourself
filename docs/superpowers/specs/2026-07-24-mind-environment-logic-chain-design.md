# “心智与环境：何时该离开”逻辑链重排设计

## 目标

让读者能连续理解：我正在面对什么风险；为什么心智不能单独解决它；外部环境怎样改变我承担风险、恢复和离开的条件；因此我该练习、止损，还是为离开做准备。

## 约束

- 不整段删除原文内容。
- 不把风险决策地图改写成另一篇社会理论文章。
- 仅调整章节顺序、标题、段落衔接和必要措辞；原有观点、例子、校正、记录模板与观点变化均保留。
- 保持自定义主题的语义职责：区分可调节痛苦与现实危险，并为离开做准备。

## 结构

1. **先保安全：一分钟分流**：保留现有分流表，确定全文的判断对象。
2. **为什么不能只靠心智**：使“不要在悬崖边练习泰然”先提出结论，再由“为什么心智不能替代安全条件”解释心智能做与不能替代的部分。
3. **环境怎样具体影响日常选择**：将“外部环境不是‘心态不好’的背景”置于本节开头，说明外部条件不是免责叙事，而是风险、恢复和退出成本的变量。原“时代怎样进入我的日常”改为这一机制的具体说明：就业、住房、医疗、关系规范和保障，经由资源、权力、恢复空间与离开成本，进入个体的日常选择。保留原始思考与“保留 / 修正”内容，但增加其对风险判断的用途。
4. **三条路径：练习、止损或先为离开做准备**：保留三条路径，开头回指风险程度、调整权、支持和退出成本。
5. **现实依据与必要校正**：保留复盘、案例与误读校正，作为前述机制和判断的证据边界。
6. **一次记录，而非继续分析**：保留记录模板，以是否增加安全和选择权验证路径是否合适。
7. **观点变化**：保留原表，说明判断如何演化。

## 修改原则

- 抽象的“时代”只在能解释具体判断变量时出现；不用它取代具体的环境条件。
- 将“时代定义人”“99% 的痛苦”等保留为待校正的原始观点，不把不可验证比例作为正文结论。
- 每个章节末尾应自然引向下一问，避免从结构判断突然跳到思想摘录。

## 验收

- 读者不阅读“原始思考”也能理解全文决策链。
- 阅读“环境怎样具体影响日常选择”后，能说出它如何改变风险、恢复、支持或离开成本中的至少一个判断变量。
- 原文件没有任何原有正文段落被整段删除；只允许移动、拆分或修改表述。
- 原有内部链接和记录模板仍有效。
