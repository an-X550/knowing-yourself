# 方向锚点与缺席项校准设计

## 背景

周复盘和月复盘已经能从日志与视角分析中归纳主题，但它们主要回答“本周期发生了什么”。当用户存在长期方向（如考公、行测、作息稳定）时，重要目标可能因为本周期缺席、日志未记录或分析漏检而没有进入报告。如果用户只根据报告写回应复盘，可能被“已出现的材料”带偏。

## 第一性原理

项目的原子价值是：

```text
价值 = (洞察质量 × 可行动性 × 闭环速度) / 使用摩擦
```

方向锚点优化服务于“决策校准”：复盘不只检查发生了什么，也检查重要但缺席了什么。AI 负责识别事实、模式和缺席证据；用户负责确认方向、取舍和验证行动。

## 目标

1. 在周 / 月复盘中显式读取当前方向锚点。
2. 对方向锚点做缺席项检查，区分“未执行”“未记录”“目标已变化”“证据不足”。
3. 将回应复盘升级为校准复盘：既回应 AI 看见的内容，也补充 AI 没看见但用户认为重要的内容。
4. 不新增命令，不增加默认使用步骤。

## 非目标

- 不新增目标管理系统。
- 不新增 `/response-review` 命令。
- 不把人生设计变成每周 / 每月必跑视角。
- 不要求用户为了复盘额外维护复杂表格。

## 设计

### 方向锚点来源

周 / 月综合 agent 按优先级读取：

1. `context.current`（`关于我/current.md`）
2. 上周期报告中的后续规划 / 下月规划 / 下周规划
3. 核心画像（`context.core_profile`）中的长期目标
4. 本周期日志中用户明确写下的目标

如果来源缺失，报告要标注“方向锚点不足”，但不能编造目标。

### 缺席项检查

对每个方向锚点检查本周期是否有行动证据。输出状态限定为：

- `有推进`：日志或反馈中有明确行动证据。
- `缺席-未执行`：方向重要，但缺少行动证据，且有拖延、替代投入或计划落空证据。
- `缺席-未记录`：用户提到做了，但日志缺少过程、数量或结果。
- `目标变化`：材料显示该方向已被用户主动降级或替换。
- `证据不足`：无法判断，需下周期补记录。

缺席项不等于失败。它是需要用户确认的校准信号。

### 报告落点

不改变六问一级标题，只在内部增加插槽：

- `回顾目标`：增加方向锚点与目标漂移。
- `评估结果`：增加方向锚点完成度 / 缺席项检查。
- `后续规划`：把重要缺席项转成下周期硬约束或验证假说。

### 回应复盘模板

方法论文档提供以下推荐结构：

```markdown
## 0. 我的方向锚点
## 1. AI 复盘中我认可的判断
## 2. AI 复盘中我不认可或觉得偏的判断
## 3. AI 没提，但我认为重要的事
## 4. 本周期最大偏离风险
## 5. 下周期不可丢的硬约束
```

## 成功标准

当用户的关键方向在日志或报告中缺席时，周 / 月复盘会把它作为校准信号暴露出来，而不是让它从后续规划中自然消失。
