# 用户版 README 首次闭环重构设计

**日期**：2026-08-01  
**状态**：已确认，待实施  
**范围**：`packaging/zhiji-user-overlay/README.md` 与导出的 `zhiji-user/README.md`

## 问题

用户版 README 是最终用户的完整指南，但当前 355 行内容将首次日志反馈、全部功能说明、命令对照、机制边界与 FAQ 并列呈现。首次用户需要完成的真实任务是一次安全、可验证的日反馈闭环，而非先理解所有低频能力。

## 决策

采用“首次闭环优先”的减法重构：先给环境前提、隐私短提示和可复制的首次日志请求；其后解释下次如何记录验证；低频功能与深入边界改为按需阅读。保留所有必要的隐私、证据和用户决定权边界。

## 内容结构

1. **首屏与首次闭环**：定位、运行前提、隐私短提示、一次可复制的日志请求，以及下一次记录实验结果的格式。
2. **日反馈的使用边界**：简要说明日志可自由叙事、结论是待验证假说、证据不足时会降级。
3. **其他能力**：一张“目的 / 自然语言 / 兼容命令”表替代独立的八个功能小节；年度回顾、人生设计、主题思考和收藏吃灰库只保留必要的适用条件。
4. **安全与查找**：合并行为假说、AI 角色与常见问题为一节；保留结果目录、完整隐私说明和 FAQ。

## 同步与约束

- overlay README 是分发源；变更后通过导出脚本刷新 `zhiji-user/README.md`。
- 用户版、overlay 与根 `VERSION` 的版本说明必须一致；当前两份 README 中的 `v1.9.5` 必须同步为发布后的版本。
- 不改变命令、输出目录、隐私行为、提示词契约或产品功能。
- 不创建额外用户文档；用户版 README 保持可独立阅读。

## 验收

- 首次用户能在首屏完成一次“日志 → 洞察 → 小实验 → 下次记录”的闭环。
- 不再重复提供首次行动入口、功能逐项说明与命令对照、以及证据边界说明。
- overlay 与导出用户版 README 内容同步，本地链接有效，分发边界和项目完整性检查通过。
- 进行一次用户视角干运行：根据 README 完成一次示例日志分析，不需要额外解释。
