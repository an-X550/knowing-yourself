# 知己用户 HTML 上手页设计

## 目标

让第一次接触知己的用户不需要启动 Web 服务、阅读开发资料或猜测配置顺序，就能从本地双击打开的页面理解项目价值、准备环境，并完成第一次“日志—反馈—验证”闭环。

## 第一性原理判断

真实问题不是缺少更多说明，而是首次用户无法快速回答四个问题：这是什么、先做什么、需要准备什么、哪些能力还需要额外授权。

已知事实：`README.md` 与 `zhiji-user/README.md` 已包含完整且可验证的产品与部署信息；用户版是最终用户分发包，根目录同时服务使用者和贡献者。飞书与滴答能力均为可选项，且第三方账号、授权和凭证必须由用户独立建立。

不可突破的约束：页面必须离线可用、不能把真实日志或凭证写入页面、不得将 AI 输出表述为事实或把可选集成表述为默认可用。

最小路径：打开 `zhiji-user/index.html` → 了解本地起步所需软件 → 打开完整用户包 → 粘贴真实日志并执行第一次日反馈 → 在下一次日志中记录实验结果。飞书与滴答只在用户已完成本地闭环且确有降低摩擦需求时再启用。

## 范围与文件边界

- 新建 `zhiji-user/index.html`：唯一完整的面向最终用户的离线说明页；不依赖 CDN、构建工具或外部字体。
- 新建根目录 `index.html`：简短的项目分流页，明确引导体验者打开 `zhiji-user/index.html`，并链接 README、状态和贡献规范。
- 修改 `README.md` 与 `zhiji-user/README.md`：各增加一个指向相应 HTML 页的显眼链接，避免形成第三套维护入口。
- 不创建 JavaScript、构建配置、图片资源、账号配置或新的运行命令。

## 用户体验与信息架构

### 用户版主入口

页面采用单页锚点导航与响应式卡片布局，首屏只保留一句价值主张、默认选择“仅本地”的第一步和进入快速开始的按钮。随后按用户决策顺序排列：

1. **它解决什么**：从记录事实到验证小行动的闭环，明确不替代诊断或人生决策。
2. **5 分钟完成第一次闭环**：下载完整用户包、安装并用 Codex 或 Claude Code 打开整个目录、发送日志提示词、下次补充实验结果。
3. **需要准备什么**：必需项为支持读写 Markdown 的 AI 工具；可选项为飞书、滴答与对应的独立授权。页面不要求用户预先安装网页运行环境。
4. **完整功能地图**：日反馈、日志教练、周/月/项目复盘、人生设计、主题思考、收藏库；每项说明适用时机与产出。
5. **按需扩展**：飞书文档沉淀、飞书智能体手机日志入口、滴答清单行动分发。每张卡明确“默认关闭”“前提”“资料链接”“数据边界”。
6. **隐私与常见误区**：本地 Markdown 为权威、真实日志默认不入 Git 但不等于加密、AI 是待验证假说。

所有外部或 Markdown 链接均使用相对路径；页面内没有自动提交、自动上传、自动授权或收集数据的行为。

### 根目录分流页

根页说明本仓库同时面向体验者与维护者，主按钮相对链接到 `zhiji-user/index.html`；次级链接分别进入根 README、项目状态与开发规范。它不重复用户版的功能清单或安装步骤，确保产品信息只有一套完整呈现。

## 内容真实性与维护策略

页面复制的功能和设置说明必须以当前 `zhiji-user/README.md`、`docs/result-distribution-setup.md`、`docs/local-feishu-daily-feedback-entry.md` 与 `docs/feishu-ai-deployment.md` 为依据。描述只使用已经存在的能力：飞书沉淀与滴答分发默认关闭；手机入口依赖在线 Windows 电脑与监听进程，通常等待 2–5 分钟；Claude/DeepSeek 后端需要按部署指南做最小适配。

版本号从 `VERSION` 读取后写入静态页面文本；本次公开文档变更会递增修订版本，并同步 README 徽章、`PROJECT_STATUS.md` 与 `CHANGELOG.md`。

## 验收标准

- [ ] 在无网络环境直接双击 `zhiji-user/index.html` 可完整阅读，不出现外部资源或脚本错误。
- [ ] 用户在首屏能找到本地起步路径，并在一个屏幕滚动内看到需要的软件与首个提示词。
- [ ] 飞书文档、飞书智能体/手机入口、滴答清单三项可选能力均说明用途、前提、默认状态和配置资料链接。
- [ ] 根目录 `index.html` 明确把最终用户导向 `zhiji-user/index.html`，不复制主页面内容。
- [ ] HTML 具备语义标题、焦点可见、移动端布局与足够文字对比度。
- [ ] 所有本地链接指向存在的文件；版本、README 徽章、项目状态与 CHANGELOG 同步。

## 不做什么

- 不制作在线部署站、埋点、登录、自动配置向导或浏览器内 AI 调用。
- 不新增飞书、滴答或任何 AI 服务的权限和凭证处理。
- 不将 HTML 替代 Markdown README；README 仍是可维护的事实来源与详细操作资料。
