# 主题思考实践根主题设计

## 目标

将《主题思考的调用、实践与生活改变》定位为主题思考的根主题：所有希望进入生活的主题，都先经过其行动质量门槛；不要求每次完整重读全文，也不把它变成新的打卡系统。

## 决策

采用“根主题必读运行核心”的方案：每次开始主题思考时，先阅读该主题的 `0. 当前行动卡` 与 `2. 当前判断`；只有修改主题库结构、复核整个系统或长期无法行动时才阅读全文。

## 运行协议

1. 判断本次内容是否会改变下一次反应、行动或验证。
2. 若会，必须落到对应主题的触发场景、最小动作与反馈条件。
3. 若不会，不强行制造行动；作为背景、价值判断或待验证材料保留。
4. 真实触发出现时，直接打开对应主题行动卡，不重新阅读全文。
5. 同类触发累计三次后，依据“触发—动作—结果”决定保留、缩小、修正或停止该动作。

## 边界

- 根主题是运行协议，不解释或替代各专题的具体判断。
- 不要求每条随想都进入行动链路。
- 高风险、不可逆或以价值取舍为主的问题，先完成必要核查，不按训练任务处理。
- 若该协议增加阅读、记录或维护负担而没有增加真实动作，应压缩协议，而不是新增工具或文档。

## 验收

- 根主题和索引明确“根主题”职责及必读范围。
- 每个新建或更新的行动型主题可回答：触发、最小动作、反馈或等待条件。
- 日常调用不要求重读全文；主题库不因一次调用困难而立即扩写或改造。
