# 知己可验证备份与安全恢复计划

**目标：** 让用户在重装或换电脑时迁移本地日志、复盘和项目，同时保证 API Key 永不导出、恶意压缩包无法越界写入、已有数据不会被静默覆盖。

**最小实现：** 主进程生成带版本、文件清单和 SHA-256 的 `.zhiji.zip`；恢复先完成只读预览和完整校验，仅允许写入空数据目录。冲突合并暂缓，因为它显著增加引用改写、事务回滚和用户决策成本，而备份/空目录恢复已经覆盖当前真实问题。

1. 测试先行：覆盖 allowlist、凭据排除、哈希校验、Zip Slip 和非空目录拒绝。
2. 实现纯主进程 `DataTransferService`，所有路径必须是规范化相对路径。
3. 通过具名 IPC 和原生 Windows 文件对话框暴露导出、预览、恢复。
4. 在设置页加入“本地数据”卡片，恢复必须先预览、再显式确认。
5. 运行完整测试、类型检查、安全审计后单独提交。
